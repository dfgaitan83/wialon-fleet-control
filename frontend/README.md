# Frontend — Wialon Fleet Control

React 19 + TypeScript + Vite. La documentación completa (arquitectura, cómo
ejecutar, decisiones de diseño y seguridad) está en el [README principal](../README.md).

```bash
npm ci          # dependencias exactas del package-lock.json
npm run dev     # http://localhost:5173 (el proxy reenvía /api al backend en :8000)
npm test        # Vitest
npm run build   # build de producción en dist/
```
